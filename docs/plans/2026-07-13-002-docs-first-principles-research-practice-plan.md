# 基于第一性原理的科研实践参考资料

## 目标

把用户提供的三篇 Notion 页面及其公开子页面、附件和直接引用的研究方法资料，整理成一份可在本仓库长期维护的中文科研实践参考资料。资料要覆盖选题、提出和验证解法、诊断实验失败、实验记录、论文阅读、讨论、写作、报告和答辩回应，并用来源台账说明每一项结论的出处与访问状态。

## 来源边界

- 种子页面：`idea`、`work` 和实验记录页面，以及公开可见的子页面和附件。
- 扩展来源：`pengsida/learning_research` 根文档，固定到提交 `6fdbcdfe24167feb7164d5625a477c75bd118040`；从这些材料直接引用、且实际承载研究方法内容的公开网页、讲义和 PDF。
- 只将相关资料综合为原创中文说明。不得镜像原文、PDF、图片、下载附件、网页抓取记录或浏览器状态。
- 对访问受阻、链接漂移或只提供目录的来源，记录限制，不从标题或上下文推断正文内容。

## 交付物

- `docs/guides/first-principles-research-practice.md`：面向日常科研工作的详细中文指南，包含可执行的检查表、模板、分工和诊断流程。
- `docs/guides/first-principles-research-practice-sources.md`：来源、获取状态、使用范围和未能读取的原因。
- `docs/START_HERE.md` 与 `docs/PLANS.md`：可发现性和完成记录。

## 非目标

- 不修改 Unified Research Protocol、基线规范、研究结论或医学推荐实验的任何政策。
- 不把教学材料包装为本项目的实验结果，也不把通用方法当作针对真实患者数据的操作许可。
- 不扩展为对互联网所有嵌套链接的无限递归抓取。

## 验证

- 检查正文中的每个来源编号都能在来源台账中解析，所有相对链接可用。
- 核对外部资料均以综合或目录形式保存，没有原始附件和临时解析文件进入 Git。
- 对修改过的 Markdown 运行 `markdownlint` 与 `git diff --check`。
