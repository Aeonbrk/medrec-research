## 收录范围与标记

收集日期为 2026-07-13。资料包包括三篇用户提供的 Notion 种子页面、其公开子页面和附件、`pengsida/learning_research` 根文档的固定提交 `6fdbcdfe24167feb7164d5625a477c75bd118040`，以及这些材料直接引用并承载研究方法内容的公开资源。直接资源中的更深层链接仅作目录记录，除非理解已收录内容确有必要。

- **已阅读**：公开页面、文件或可访问的文本已读，并被综合进指南。
- **部分可读**：只能读到目录、摘要或已迁移的目标页面；未从不可见正文推断结论。
- **受阻**：公开访问失败；不使用其内容。
- **背景**：可访问，但只提供课程、个人或领域背景，不支撑指南中的通用方法结论。

上游 GitHub 仓库要求复用者引用来源，但根目录未给出可供本次确认的仓库许可证。本仓库只保留原创中文综合和简短来源说明，不镜像原始材料。

## 获取方式与保留边界

先以只读方式尝试 `markdown.new`；Notion 页面只返回通用元数据时，改用公开浏览器读取可见文本。PDF 和 PNG 只下载到仓库外的临时目录，并用 LiteParse 读取一次。临时原件、解析文本、浏览器状态和网络轨迹均不纳入版本控制。

本台账不承诺对互联网做无限递归抓取。“外链”只在下列情况进入实质阅读范围：它由种子材料直接指向，且提供研究方法、讲义、附件或理解种子材料所必需的内容。目录、个人资料、课程聚合和无法可靠取得的页面仍被记录，从而让后续维护者知道哪些内容已核对、哪些没有。
