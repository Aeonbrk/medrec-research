# Research contract v1: HITL control-console vertical slice

## Hypothesis

Under the existing Action Gate, H1/H2, Reproduction Mode, and privacy boundaries, a server-registered execution declaration plus durable replayable state can carry one GAMENet source-native lane from an opaque request to a blocked or reviewable Decision Packet without allowing browser or automation to change scientific meaning.

## Frozen setting

- Project: `medrec-research`.
- Control plane: local production Python harness recorded by actual Git revision.
- Initial lane: `gamenet`, source-native Reproduction Mode.
- Source identity: SafeDrug main `88ce5c377dcdc2aa01aaa88f5478dfa4373ba49a`.
- Source-native seed: `1203`; no seed argument or source patch is permitted.
- Checkpoint selection: source-owned `best_epoch` from evaluation data, never test-result selection.
- Browser authority: bounded contract/H1/H2 inputs and opaque Action Gate `request_id` only.
- Evidence boundary: public-safe aggregate records and approved immutable URLs only.
- Local proof: production harness, synthetic/no-data execution state, package, security, Playwright, axe, and screenshots.
- Real canary proof: unavailable until explicit 319/data/GPU/time/cost/license/environment authorization.

## Success signals

- One request maps to one declaration and one attempt across duplicate submission and restart.
- Protected binding drift blocks resume.
- Non-waivable authority, privacy, legality, integrity, or absolute-resource failure records cancellation and blocks dependents.
- General scientific exceptions return to the pending queue and never trigger code, split, metric, contract, hyperparameter, or strategy changes.
- Public-safe evidence produces a current Decision Packet; H2 remains human-only.
- Production desktop/mobile UI completes review and decisions with keyboard and both themes.
- No Radix runtime dependency remains after migration.

## Independent failure signals

- Browser-controlled argv, remote identity, path, environment, resource, credential, revision, contract digest, or packet digest.
- Fixture/mock fallback in production.
- Duplicate side effects from one request.
- Downstream advancement after failed or stuck dependency.
- Silent repair that changes scientific behavior.
- Reproduction evidence presented as Comparison evidence.
- Base UI migration breaks focus, keyboard, overlay, Sheet, table, or state semantics.

## Resource and repair boundary

- Local work may use the repository toolchain and public-safe synthetic state.
- No real-data, GPU, 319 write, environment mutation, source synchronization, cost-bearing run, license determination, credential use, or formal experiment without explicit human authorization.
- Automatic repair is limited to declaration-listed idempotent retry, checkpoint resume, endpoint recovery, and bounded resource recovery that does not change scientific semantics.
- Code changes, data split changes, metrics, contract fields, undeclared hyperparameters, and execution strategy changes always require a new human decision.

## Stop conditions

Stop and return to the pending queue when authority, privacy, data/evaluation integrity, evaluator completeness, evidence chain, license, readiness, source identity, environment identity, or absolute resource limits fail. Stop remote work before it starts when authorization is missing.
