# Competing hypotheses

## H-A: Missing durable orchestration is the primary control failure

If true, binding one Action Request to a registered declaration and replayable state machine will eliminate ambiguous execution state without changing Action Gate or scientific records.

Minimal distinction: restart the production harness during queued/running synthetic work, replay the same request, and verify one attempt identity, one state history, and no duplicate side effect.

## H-B: Missing scientific identity binding is the primary control failure

If true, durability alone is insufficient. A queue item without current contract, H1, H2, revision, target, environment, resource, and evidence bindings can resume the wrong work.

Minimal distinction: mutate each protected binding independently and verify the queued declaration becomes blocked rather than resumed.

## H-C: Decision latency is primarily an information-architecture failure

If true, a pending-first three-column workbench with progressive evidence will reduce navigation and reconstruction work while preserving decision quality.

Minimal distinction: production Playwright tasks for H1, exception review, Decision Packet review, and H2 must complete on desktop and mobile without visiting unrelated sections or exposing hidden authority fields.

## H-D: GAMENet is blocked mainly by operational drift, not model code

If true, reconciling source-native launch, fixed seed `1203`, source-owned checkpoint selection, license, environment lock, adapter boundary, and remote revision will reach a valid canary without modifying Baseline Core behavior.

Minimal distinction: after explicit authorization, one low-cost source-native canary must pass preflight, fixed launch, monitoring, public-safe intake, core acceptance, Decision Packet assembly, and H2. Failure before model execution supports an operational blocker; a scientifically invalid completed run does not support Comparison readiness.

## H-E: A full remote worker is premature before declarations and no-data rehearsal

If true, implementing arbitrary remote execution now would add risk without discriminating system correctness.

Minimal distinction: local no-data rehearsal must prove every state, blocker, cancellation, replay, and H2 gate using the production harness while the bridge remains blocked from remote submission.
